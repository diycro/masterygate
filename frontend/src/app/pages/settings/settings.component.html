Your API key, your browser, your data

This app runs entirely in your browser. Curriculum content ships with the app; your progress lives only in this browser's local storage; and grading / "generate more questions" / mock interviews call your own Groq, OpenAI, or Anthropic API key directly from your browser. The key is never sent anywhere except straight to that provider.

LLM provider

Groq's free tier covers every model it hosts — no model is paid-only, you just share one rate limit (30 req/min, 14,400/day) across all of them. No card required. OpenAI has no ongoing free tier — every model is billed per token from your first request. Anthropic has no ongoing free tier — every model is billed per token from your first request.

Get a key from console.groq.com/keys platform.openai.com/api-keys console.anthropic.com/settings/keys — stored only in localStorage on this device.

YouTube videos — optional

Each module page can show real, highly-viewed tutorial videos ranked by view count instead of a blind search link. This needs your own free YouTube Data API v3 key, called directly from your browser — never sent anywhere else.

Get a free key from the Google Cloud Console — create a project, enable "YouTube Data API v3", then create an API key under Credentials. Free tier: 10,000 quota units/day (roughly 75-100 module lookups) — stored only in localStorage on this device.

Local progress

Gate passes, course completion, resource checkmarks, and mock-interview history all live in this browser only. Clearing your browser's site data (or a different browser/device) starts fresh.
